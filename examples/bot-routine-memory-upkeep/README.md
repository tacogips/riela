# Bot routine and memory upkeep

Create a bot, attach a daily routine, and run its triage workflow with a mock
response. The bot overview shows the scheduled routine and completed run.
A second mock response consolidates the bot's riela memory so you can inspect
the audited change and undo it.

Follow [the walkthrough](EXPECTED_RESULTS.md) from the repository root.
See [Bots](../../docs/bots.md) for the command reference.
